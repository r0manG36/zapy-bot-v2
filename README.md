MODO DE USO:

Hay dos formas de comuncicarte con Zapy(Bot). Una de las formas es mencionando al bot y preguntandole lo que quieras, el bot crea un hilo privado y dentro del hilo te habla, 
el bot esta diseñado para organizar tu rutina o organizar tareas con la rutina que hayas metido anteriormente asi que no te va a responder a todo, puedes cambiar horas de tarea y 
todo hablandole otra vez sin tener que volver a mencionarle. La segunda forma es con comandos usando la ! al principio de toods los comandos, para abrir la biblioteca de comandos usa 
!comandos, dentro de la biblioteca de comando estan los siguientes comandos: (!configuracion !eventos !añadir Nombre | AAAA-MM-DD !apuntes Asignatura | Tema !clear).


RECOMENDACIONES: 

EMPIEZA POR CONFIGURAR TU PERFIL PARA QUE NO HAYA ERRORES USANDO !configurar, TEN PREPARADO UN NOTION CON CALENDARIO, UNA BASE DE DATOS PARA LAS ASIGNATURAS, UNA API DE NOTION,
